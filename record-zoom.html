Zoom Web 2-Track Recorder

Tab-audio capture works without any OS screen-recording permission.

    How to use / notes
    
  
      
    
    1. Join the Zoom meeting with the browser client (invite link → "Join from your browser").
      2. 
    
    2. Click start → pick the Zoom tab in the share dialog and check "Share audio" (share the tab, not the whole screen!).
      3. 
    
    3. Never mute the Zoom tab while recording (muted tab = silent recording). Switching to other tabs is fine.
      4. 
    
    4. Only record meetings you are allowed to record.
      5. 
    
    5. Server mode: recordings are uploaded to the server's recordings/ directory and you can transcribe right from this page.
      
        Local mode (opened as a file): recordings are saved via the browser dialog — then run python transcribe_meeting.py <name> yourself.
